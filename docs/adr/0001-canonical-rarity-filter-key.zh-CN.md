# 以 `rarity` 作为规范过滤键，并用 `rarities` 保持向后兼容

[English](0001-canonical-rarity-filter-key.md)

稀有度过滤现在覆盖词缀、梦魇地下城钥匙和贡品过滤器。贡品此前已经使用复数键
`rarities`，但为了让所有过滤器使用一致词汇，我们将单数键 `rarity` 定为规范格式。
贡品仍把 `rarities` 作为验证别名，因此现有 Profile 可以继续加载。输入会先规范化
（裸字符串转为列表，并转成小写），然后根据 `ItemRarity` 枚举严格验证；规范的存储形式
始终是小写列表。

## 考虑过的方案

- **贡品继续使用 `rarities`，仅词缀使用 `rarity`**：拒绝。同一概念长期使用两个键会造成词汇混乱。
- **将贡品直接改为 `rarity`，不提供别名**：拒绝。这样会导致现有贡品 Profile 无法加载。

## 影响

- Pydantic 内部字段仍名为 `rarities`，因此过滤代码继续读取 `model.rarities`；只有序列化和验证别名不同。
- 共享的“先规范化、再验证”辅助函数是解析稀有度输入的唯一位置。
