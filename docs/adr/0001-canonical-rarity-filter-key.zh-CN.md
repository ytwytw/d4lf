# 规范 `rarity` 过滤器键，附带 `rarities` 向后兼容别名

**简体中文** | [English](0001-canonical-rarity-filter-key.md)

稀有度过滤现已覆盖词缀、符印（sigil）和贡品（tribute）过滤器。贡品此前已使用复数形式 `rarities` 键，但我们将所有过滤器统一规范为单数 `rarity` 键，以获得一致的词汇。贡品保留 `rarities` 作为校验别名，以便现有配置文件仍可加载。输入会被规范化（裸字符串 → 列表，大小写折叠为小写），然后严格对照 `ItemRarity` 枚举进行校验，因此规范的存储形式始终是小写列表。

## 考虑过的选项

- **贡品保留 `rarities`，仅词缀使用 `rarity`** —— 已否决：同一概念在不同过滤器类型间使用两个键，是持久的词汇异味。
- **贡品重命名为 `rarity` 且不设别名** —— 已否决：会破坏现有贡品配置文件的加载。

## 影响

- 内部 Pydantic 字段仍命名为 `rarities`（过滤代码读取 `model.rarities`）；只有序列化/校验别名不同。
- 共享的"先规范化再校验"辅助函数是解析稀有度输入的唯一位置。
