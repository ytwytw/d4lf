# 从 sigils.json 的 rarities 映射推导梦魇地下城钥匙稀有度

[English](0002-sigil-rarity-derivation.md)

《暗黑破坏神 IV》不会在钥匙对象上直接提供稀有度，因此过滤用稀有度需要推导：依次检查
钥匙词缀（`item.affixes + item.inherent`），在 `sigils.json["rarities"]` 中找到的第一个
词缀决定稀有度。没有任何词缀能解析出稀有度时，该钥匙的稀有度未知。

非空的钥匙 `rarity` 过滤条件与白名单之间是 OR 关系：推导稀有度在所选列表中，或任一
白名单规则匹配时，该钥匙匹配 Profile。黑名单仍然用于排除，并遵循配置的优先级。未知
稀有度不会匹配稀有度选择器，但匹配的白名单规则仍可保留该钥匙。无法解析的查找会写入
debug 日志，以便发现映射缺口。

## 影响

- `sigils.json` 中此前未使用的 `rarities` 映射成为稀有度选择器的必要数据；映射缺口不会阻止明确的白名单匹配。
- 单独使用 `rarity: [rare]` 不会意外放过未知稀有度钥匙；debug 日志用于发现数据覆盖不完整。
