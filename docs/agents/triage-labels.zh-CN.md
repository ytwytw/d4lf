# 分诊标签

**简体中文** | [English](triage-labels.md)

技能以五个规范分诊角色进行表达。本文件将这些角色映射到本仓库 issue 追踪器实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本追踪器中的标签  | 含义                         |
| -------------------------- | ----------------- | ---------------------------- |
| `needs-triage`             | `needs-triage`    | 维护者需要评估此 issue       |
| `needs-info`               | `needs-info`      | 等待报告者提供更多信息       |
| `ready-for-agent`          | `ready-for-agent` | 已完整描述，可交给 AFK agent |
| `ready-for-human`          | `ready-for-human` | 需要人工实现                 |
| `wontfix`                  | `wontfix`         | 不会被处理                   |

当技能提到某个角色时（例如"应用 AFK-ready 分诊标签"），使用此表中对应的标签字符串。

编辑右列以匹配你实际使用的任何词汇。
