# 战利品工具

在主界面点击 **战利品工具**，可打开游戏过滤器生成器、完整物品导出或装备资料库。
每个 Profile 行的 **工具** 菜单也可打开关联该方案的过滤器或装备资料。

过滤器生成器和资料库可离线使用。物品导出需要进入游戏并连接 TTS。
安装方法见 [README](../README.md#%E5%AE%89%E8%A3%85)，更换版本见[升级与回退](../README.md#%E5%8D%87%E7%BA%A7%E4%B8%8E%E5%9B%9E%E9%80%80)。

## 游戏过滤器

设置地面掉落的显示、隐藏和颜色规则，导出代码后可在游戏内使用。
D4LF 的 Profile 则用于背包和仓库物品的匹配与标记。

### 创建与编辑

可以选择以下任一种方式开始：

- **从 Profile 生成**：选择已保存的方案，点击 **从所选 Profile 生成新副本**。
- **独立创建**：点击 **新建独立过滤器**，手动添加规则。
- **导入已有代码**：点击 **导入游戏代码**，粘贴从游戏中导出的代码。

规则可以添加、编辑、排序、启用或停用。每条规则可设置名称、显示／隐藏／改色动作，
以及物品强度、稀有度、部位、词条、暗金等条件。游戏按顺序匹配规则，最多支持 25 条。

从 Profile 生成时，部分条件无法直接转换，例如未解锁外观、圣化装备保护和数值百分比。
窗口会列出转换差异，并显示当前是否会隐藏物品。
需要按 Build 筛选地面掉落时，勾选 **按 Build 筛选掉落装备** 后重新生成，再检查结果。

### 保存与游戏内导入

1. 点击 **保存**，将过滤器保存为可继续编辑的 JSON 文件。默认目录为 `%USERPROFILE%\.d4lf\native_filters`。
1. 点击 **复制游戏代码** 或 **导出 TXT**。
1. 在游戏的战利品过滤器界面导入代码，并检查各条规则。

JSON 文件供 D4LF 编辑使用，游戏内导入使用复制或 TXT 导出的代码。
修改 Profile 后，需要重新生成并在游戏内再次导入。已保存的过滤器不会随 Profile 自动更新。

导入已有代码时，如果包含当前编辑器不支持的内容，对应部分会限制编辑并保留原文。
过长的过滤器名称可能被游戏替换为默认名称；未设置的物品强度上限也可能被游戏填入默认值。
例如，游戏 `3.2.2.73764` 会将只设置最小值 100 的规则显示为 100～900。

## 完整物品导出

扫描可访问仓库、背包和穿戴物品，将物品信息保存为 Markdown、TXT 或 JSON。
三种格式包含相同的数据，Markdown 和 TXT 另有便于阅读的物品列表。

### 开始扫描

1. 进入角色，在城镇打开仓库，等待 D4LF 显示 TTS 已连接。
1. 停止其他游戏自动操作，关闭巅峰悬浮层、信息面板和诊断录制。
1. 若开启了“仅视觉模式”，先关闭它。扫描需要点击页签和移动鼠标，结束后可重新开启。
1. 打开 **战利品工具 → 完整物品导出**，选择格式，点击 **开始导出**。
1. 扫描期间保持游戏在前台，暂时不要移动鼠标或使用过滤、物品转移热键。
1. 完成后点击 **打开导出文件**。默认保存位置为 `%USERPROFILE%\.d4lf\exports\inventory`。

扫描范围包括开放的仓库页、五类背包（装备、神符、镶嵌物、消耗品、钥匙）、当前穿戴装备和护符／封印面板。
收藏、已标记为垃圾和无法解析的物品也会记录。扫描只读取物品，不会移动、装备、使用、出售或分解它们。

需要提前停止时，点击 **取消并保存已读取物品**。失去游戏焦点、TTS 断开或扫描中断时，也会保存已读取的部分。
每次扫描生成一个新文件。

### 导出内容

每件物品记录所在位置、收到的原始说明、可识别属性、标记和读取状态。
可识别信息包括名称、类别、物品强度、数量、等级要求、耐久度、回火次数等，具体取决于游戏播报的内容。
同名、同属性的物品按位置分别记录。未识别的物品仍会保留已读到的原文。

导出依赖游戏屏幕阅读器提供的文本。未播报的镶嵌内容、属性或状态可能无法取得，对应字段保留为未知。
部分说明会保留为原文，无法单独分成固有、随机、回火或精铸词条。
读取到完整原文，也可能仍有属性没有单独解析出来。

### 完成状态

| 状态     | 含义                                                                   |
| -------- | ---------------------------------------------------------------------- |
| 完成     | 预定范围扫描结束，所记录物品的原文通过完整性检查；个别属性仍可能未知。 |
| 部分完成 | 部分页面、物品或界面恢复出现问题，文件中保留原因。                     |
| 已取消   | 保留停止前已读取的结果。                                               |
| 扫描失败 | 尚未取得物品就已失败；保存目录不可写时，也可能没有导出文件。           |

无法访问的页面会记录在扫描范围中。字段中的 `null` 或 `unknown` 表示未能确认，不能按零或“没有”理解。
收藏状态只有在当前物品的 TTS 标题明确播报收藏时才为 `true`，否则为 `null`。

JSON 顶层记录程序版本、语言、开始和结束时间，以及以下内容。Markdown 和 TXT 末尾也附带完整数据。

| 字段                     | 内容                                      |
| ------------------------ | ----------------------------------------- |
| `scopes`                 | 扫描范围、访问结果和错误                  |

| `location`               | 物品所在仓库、背包或穿戴位置              |

## 装备来源与词条

用中文名、英文名或部位搜索装备，查看物品说明、已收录的获取来源、固有词条、主要词条、可选词条组和数值范围。
从 Profile 的工具菜单进入时，可以只显示该方案明确指定的装备。
Build 正文中列出的替代装备需要单独搜索。

词条种类固定时，数值仍可能在一定范围内浮动；具体以装备详情中的说明为准。
资料库展示的是装备参考数据，角色身上某件物品的实际数值请查看游戏内说明。

当前资料版本为 **3.2.1.73552**，日期为 **2026-10-05**，随程序提供，不会自动联网更新。
中英文资料分别显示，缺少译名、掉落地点或概率时显示未知。
普通传奇装备的完整获取资料尚未收录，已有掉落资料也可能与当前赛季不同。
数据来源见[资料来源说明](../assets/equipment_knowledge/NOTICE.md)。

## 本地文件

Profile、默认保存的过滤器和导出文件都在 `%USERPROFILE%\.d4lf` 下，可随此目录一起备份。
在保存窗口另选位置的文件需要单独备份。

物品导出文件保存在本机。公开分享导出文件、诊断截图或日志前，请检查其中的角色信息、聊天、路径等个人信息。

## 故障排查

| 现象                             | 处理方法                                                                        |
| -------------------------------- | ------------------------------------------------------------------------------- |
| 没有“战利品工具”入口             | 检查启动的程序版本和路径，确认打开的是新版 EXE。                                |
| 提示先进入角色或等待连接         | 进入角色，检查屏幕阅读器、第三方屏幕阅读器、DLL 安装及语言设置，等待 TTS 连接。 |
| 提示另一项操作正在运行           | 停止过滤或物品转移，关闭巅峰悬浮层、信息面板和诊断录制。                        |
| 找不到仓库页或背包分类           | 在城镇打开仓库，关闭遮挡面板，检查游戏显示设置。                                |
| 焦点丢失、TTS 持续播报或扫描中断 | 让游戏保持前台，停止其他输入和连续环境播报后重新扫描。                          |
| 文件保存失败                     | 检查保存目录权限和磁盘空间，关闭占用文件的程序；`.tmp` 文件是未完成的临时文件。 |
| 游戏拒绝过滤器代码               | 检查代码是否完整，尝试缩短名称，并检查规则数量和生成器提示。                    |
| 装备资料库不可用                 | 重新解压同一版本的完整程序包，确保 EXE 和 assets 版本一致。                     |

反馈问题时，请提供程序版本、游戏语言、显示设置、操作步骤和错误信息。
