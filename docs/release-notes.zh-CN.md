# 10.0.7+zhcn.3 版本说明

完整程序包为 `d4lf_v10.0.7+zhcn.3.zip`，可在 [Releases](https://github.com/ytwytw/d4lf/releases) 下载，解压到新目录后使用。

## 新功能

- 游戏过滤器生成器：从 Build / Profile 生成，也可独立编辑、保存和导出游戏代码。
- 完整物品导出：扫描可访问仓库、背包和穿戴物品，导出 Markdown、TXT 或 JSON。
  文件包含物品原始说明、可识别属性、所在位置和读取状态。
- 装备资料库：中文搜索 380 件具名装备及 1070 条词条记录，查看资料提供的来源、词条和浮动范围。

入口、操作步骤和保存位置见[战利品工具说明](loot-tools.zh-CN.md)。

## 修复与改进

- 合并上游 `10.0.7` 的启动、热键、Build 导入和第 15 赛季数据更新。
- 修复切换视觉模式后“立即重新启动”可能导致后台停止的问题。
- 修复部分 InfinityBuilds、Maxroll 和 Mobalytics 导入失败或识别错误。
- 补充中文名称和装备词条资料；同名装备结合部位或完整效果识别，信息不足时保留未知。
- 修复物品重读成功后仍提示截断、系统充放电通知被误认为物品的问题。
- 收藏状态仅在当前物品 TTS 明确播报时确认，避免把未确认状态当作未收藏。
- 物品导出：
  - 每页先等物品图标显示稳定再判断格子；看似为空的格子会再悬停一次确认，降低漏记暗色或较小物品的可能。空格较多时扫描变慢。
  - 既没有读到物品、也无法确认为空的位置单独列出（`unverified_slots`），不再记为读取失败的物品；此时结果为“部分完成”。
  - 垃圾标记与收藏相同，只在 TTS 标题明确播报时为 `true`，否则为 `null`；截图判断另存并标为 `unverified`。
  - 补回梦魇符印等物品被单独播报的标题；被截断的原文不再重复记录。
  - Markdown 中每件物品的原文放在代码块中并保持分行；文件格式版本为 `schema_version: 2`，新增字段见[战利品工具说明](loot-tools.zh-CN.md)。
  - 扫描中按退出热键会立即停止游戏输入，先保存为“已取消”再退出；开始新扫描或导出失败时，“打开导出文件”不再打开上一次的文件。
  - 减少扫描期间整份文件的重复写入。
- Profile 编辑器：中文同名条目（如“巨人贡品”“毒素伤害”“暗影伤害”）显示英文名和简短说明，可分别选择和删除，不再被保存为另一条目。
- 已启用的 Profile 文件缺失或无法读取时，装备过滤不再把未匹配物品标记为垃圾或丢弃，带筛选的刷新会保留现有标记；
  缺失的 Profile 不再被自动移出启用列表。托盘和日志以中英文说明受影响的方案和恢复方法。
- 导入的部位规则不再要求超过可识别词条所能证明的数量；词条无法识别时放宽该部位规则，并在导入窗口提示。
  旧 Profile 中要求数量多于所列词条的规则按“全部所列词条”处理，并在日志中提示。
- 导入时只有 Build 网站的词条文字与 D4LF 词条完全对应才会采用，不再按相似度猜测。
  修复 d4builds Build 在中文客户端下导入后词条变成无关词条、Maxroll 部分套装封印词条错误或导入失败等问题。
- Build 中有 D4LF 无法识别的物品（未知的暗金、符文之语、物品类型，或无法读取的护符／封印）时，
  整个导入会在写入任何文件前停止，并列出这些物品。
- 再次导入同名 Build 时，不会覆盖已修改的 Profile，而是另存为 `名称_2` 等新文件；Profile 保存时先完整写入临时文件再替换。
- 游戏过滤器：D4LF 开启先祖传奇保护时不会启用隐藏；同时启用多个 Profile 时，提示过滤器只包含所选 Profile。
- 装备过滤不再采用悬停前就已开始的物品播报，减少把上一件物品的说明用于当前物品的情况。
- 过滤器资料缺失或损坏时提供错误提示和重新解压建议。
- 自动更新更可靠：发行包在发布前按更新器的同一套规则校验；
  检测到 `d4lf.exe` 被占用时（例如以管理员身份运行的 D4LF），更新器会在复制前停止并提示关闭后重试。
  其他文件复制失败时，请从完整程序包重新解压。
- 设置无法加载时，提示中的日志位置改为程序目录下的 `logs`。
- 从快捷方式或其他工作目录启动时，更新检查记录仍保存在程序目录。
- DLL 未签名时的提示改为实际提供的脚本名 `install_dll.cmd`。

## 已知限制

- 部分物品和词条尚未收录；`resistance` 使用英文回退。中文客户端中名称或词条无法识别的物品会被跳过，
  不会被标记为垃圾、收藏或丢弃。
- 中文名“恶毒”（威能）和“巨人贡品”（贡品）各对应两个不同条目。D4LF 只在同一物品说明中的效果文字能确认时识别，
  否则保持未知，不会猜测为其中任一条目。这一识别尚未在当前游戏中实测，相关物品可能始终显示为未知；
  使用相关规则前，请先在“仅视觉模式”下检查结果。
- 物品导出依赖游戏屏幕阅读器提供的文本，部分属性无法单独解析，未读取到的字段保留未知。
- 空的穿戴、护符或封印槽位目前无法确认为空，有空槽位的角色导出结果为“部分完成”。
- 装备资料版本为 **3.2.1.73552**，掉落信息可能与当前赛季不同。
- 高亮模式需要游戏使用小或中字体；大字体可使用快速视觉模式。

## 升级与回退

退出 D4LF，备份 `%USERPROFILE%\.d4lf` 及另存的文件，保留旧完整程序目录，
再将新版本完整解压到新目录。首次启动核对版本、语言、热键和 Profile，以“仅视觉模式”检查结果。

从 `9.3.7+zhcn.beta.5` 或 `beta.6` 升级：这两个测试版已关闭自动更新，请按上述步骤手动下载并解压完整程序包。
V9 的 Profile 如无法加载，请重新导入。本版的 `saapi64.dll` 与这两个测试版相同；
游戏目录中的 DLL 已按说明安装并签名时，无需仅为本次升级重新运行 `install_dll.cmd`。

回退前另存新版运行后的配置，再启动旧完整程序；若不兼容，保留两份备份后恢复升级前配置。
应用升级和回退不会自动替换游戏 DLL，只有对应版本说明要求时才在关闭游戏后重新安装。
详细步骤见 [README](../README.md#%E5%8D%87%E7%BA%A7%E4%B8%8E%E5%9B%9E%E9%80%80)。
