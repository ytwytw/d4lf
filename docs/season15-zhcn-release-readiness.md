# S15 简中版发布前 review（2026-09-18）

## 范围与发布结论

审查对象是 `codex/zhcn-v10.0.3-s15` 工作区，基于上游 `v10.0.3`；中文修订版本为 `10.0.3+zhcn.1`。
本轮覆盖解析、本地化来源、物品操作安全、桌面生命周期、更新器、打包、发布流程和测试。
本轮没有推送、创建标签或发布 GitHub Release。

这是发布前工程审查，不等于所有职业、分辨率、语言、装备和操作的穷举验收。
本轮实机只读测试与离线回归分开记录；禁止把单元测试通过当成自动标记/丢弃已经实机验收。
完整中文无人值守发布仍必须满足数据质量门禁，以及本文末尾的验收边界。

结论：本轮发现并能复现的工程缺陷已修复，源码、冻结 EXE 和所列实物样本通过验证；
**不批准完整中文无人值守正式发布**。尚有 13 个贡品缺少可靠简中译文及“恶毒”威能歧义，
也没有在用户物品上验证自动标记、丢弃或搬运。保留这些明确边界，不伪造译文或把只读通过推广成全功能通过。

另一个高优先级打包缺陷是在实际启动 EXE 时发现的：PyInstaller 从外部工具 PATH 收入了不兼容的
ICU DLL，导致 QtGui 无法加载。对真实 PE 导入/导出及哈希核对后，构建已改为仅向子进程提供
Python 与 Windows 必要搜索路径；不修改系统环境。独立 Qt 冻结包已成功运行。

禁用分类沿用上游有测试覆盖的语义：该分类的全部物品（包括 Mythic）跳过，不收藏、不标垃圾；
启用分类时 Mythic 始终保留。没有为了匹配过时文档而改变运行时行为。

Tk 清理后，所属 daemon 线程保留已退休的 Tcl interpreter，直到进程正常结束，避免仍被单例引用的
widget 在错误线程析构；它不再处理 UI 或游戏输入，也不阻塞 Qt 正常关闭。不能把这个方案描述为所有线程均已 join。

## 不能据此宣称已经完成的验收

- 自动收藏、标记垃圾、丢弃、物品搬运：本轮不对用户装备执行破坏性验收，只有离线安全回归。
- 延迟 TTS 与悬停物品关联：新帧序号阻止复用已完成旧帧，但不是游戏提供的物品唯一标识；仍需要复杂延迟场景实机验收。
- 显式 `force_refresh` 会在重新读取前重置已有标记；“无新帧不进行标记”仅描述后续筛选步骤，不代表该选项整体零输入。
- 所有新增暗金、套装及职业组合：仅已记录的实物样本属于实机证据。
- 旧版本原地自动升级与回滚：新脚本离线验证，不代表旧版本已分发的脚本被追溯修复；本次优先手动解压到新目录。
- 纯净 Windows 用户环境、不同分辨率/字体和逐词缀高亮：只能按实际测试范围说明，不能由本机快速模式结果推广。
- 缺乏可靠中文来源的记录不机器翻译补空，不以英文回退当作中文完整支持。
